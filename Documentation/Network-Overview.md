# Network Overview

## Project Description

This project simulates the deployment of a secure Cisco-based network for Baker Digital Solutions, a small business with seven employees.

The network has been designed to provide secure internet access, departmental segmentation, shared network resources, and secure management while remaining scalable for future expansion.

## Network Components

* Cisco ISR 4321 (ISP Router)
* Cisco 1941 (Business Router)
* Cisco Catalyst 2960 Switch
* Cisco Aironet Wireless Access Point
* File Server
* Network Printer
* Seven Employee Workstations

## Network Services

* DHCP
* IPv4 Addressing
* Inter-VLAN Routing
* Wireless Networking
* Shared Printing
* Shared File Storage
* SSH Remote Management

## Network Goals

* Secure communication
* Reliable connectivity
* Centralized resource sharing
* Scalability
* Ease of management

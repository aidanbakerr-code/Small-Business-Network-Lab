# VLAN Design

## Purpose

Virtual Local Area Networks (VLANs) are used to separate departments into individual broadcast domains, improving security, performance, and network management.

## VLAN Assignments

| VLAN ID | Name           | Purpose                      |
| ------- | -------------- | ---------------------------- |
| 10      | Management     | Executive devices            |
| 20      | IT             | IT administration            |
| 30      | Finance        | Financial systems            |
| 40      | Sales          | Sales department             |
| 50      | Marketing      | Marketing department         |
| 60      | Support        | Customer support             |
| 70      | Administration | Reception and administration |
| 80      | Servers        | Servers and shared resources |
| 90      | Guest          | Guest wireless access        |
| 99      | Management     | Network device management    |

## Design Benefits

* Reduced broadcast traffic
* Improved security
* Easier troubleshooting
* Simplified administration
* Better scalability

# Security Plan

## Objectives

The network has been designed using industry best practices to protect company resources and ensure secure operation.

## Security Measures

* Departmental VLAN separation
* SSH for secure remote device management
* Strong encrypted device passwords
* Port security on access ports
* Disabled unused switch ports
* Static addressing for infrastructure devices
* Guest network isolation
* Configuration backups
* Principle of least privilege for administrative access

## Future Security Enhancements

* Access Control Lists (ACLs)
* VPN Remote Access
* Syslog Server
* Network Time Protocol (NTP)
* AAA Authentication
* Network Monitoring
